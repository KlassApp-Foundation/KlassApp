# Commands

## Section naming convention: P = Primary, S = Secondary
Section names in this project use letter-prefix notation: P.1 through P.7 = Primary One through Primary Seven; S.1 through S.6 = Senior One through Senior Six. "P" always means Primary, "S" always means Secondary (Senior level). When writing section-classification logic (regex, prefix matching, etc.), use this convention — not "Primary One" long-form strings. Nursery sections use word names: Baby Class, Middle Class, Top Class.
