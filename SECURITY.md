# Security Policy

## Supported versions

KlassApp is actively developed on the `main` branch of this repository. The hosted product runs on Laravel Cloud at [https://klassapp.xyz](https://klassapp.xyz).

Security fixes are applied to current `main` and deployed through the project's normal release path. Older forks or unofficial mirrors are out of scope.

## Reporting a vulnerability

**Do not open a public GitHub issue for an undisclosed security vulnerability.**

Email **community@klassapp.xyz** with:

- A short description of the issue and its impact
- Steps to reproduce, or a proof of concept if you have one
- Affected URL, environment (production / staging / local), and approximate discovery date
- Your preferred contact method for follow-up

Please keep the report confidential until we confirm a fix is available or we agree otherwise.

## What to expect

We will acknowledge security reports sent to **community@klassapp.xyz** and work with you on next steps. We do not publish a fixed response-time SLA here.

If the report is accepted, we will coordinate disclosure timing with you when a fix is ready. If it is declined (for example, out of scope or not reproducible), we will say so clearly.

## Safe harbor

We welcome good-faith security research against KlassApp. Do not access or modify other schools' data, disrupt service, or exfiltrate personal information beyond what is needed to demonstrate the issue. Use demo or your own test accounts whenever possible.

## Non-security bugs

Product bugs, UX issues, and feature requests belong in GitHub Issues (see `.github/ISSUE_TEMPLATE/`) or can be emailed to **community@klassapp.xyz**.
