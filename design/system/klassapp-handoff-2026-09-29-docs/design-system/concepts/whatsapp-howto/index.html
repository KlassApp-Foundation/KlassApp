WhatsApp how-to format

Short, text-only how-tos sent from the school's KlassApp number or by KlassApp support. They use only WhatsApp's own formatting and render the same on a basic Android phone. The chat bubbles below are a WhatsApp-like preview drawn in HTML. They weren't sent through WhatsApp, and the character counts are measured by script on the source text. Check before sending: the menu paths, the 7-day link expiry and the /docs/help/ page paths are sample values. Confirm each one against the live app and the chosen docs domain.

Length

At most 500 characters and 5 steps. That fits one screen on a 5.5″ phone without "Read more". If a task needs more, send the link only.

Shape

Line 1 is *Title*, the task as a verb ("See your child's report card"). Next come numbered steps, 1. to 5., one action per line. Then one line on what happens next. The last line is the link.

Formatting

Only *bold*, for button and menu names exactly as they appear on screen, and for the words to send. No italics, no ``` monospace, no bullet characters (numbers only), and no ALL CAPS.

Emoji

None. The brand uses no emoji, and some older phones show them as boxes. Don't use Unicode arrows either; write "then".

Link

On its own last line, as the full https:// URL of the doc page: https://klassapp.xyz/docs/help/…. Don't use link shorteners, because parents trust the domain they can read. Add ?src=wa only if analytics needs it.

Tone

Talk to one person as "you". Use plain words and short sentences. Name buttons exactly as the app does. Don't say "simply", "just" or "easily". Never ask for a password or PIN in a how-to. Voice guide
