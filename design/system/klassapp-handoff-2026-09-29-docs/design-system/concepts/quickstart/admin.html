KlassApp quick start

Get Demo Junior School running in KlassApp.

For admins
1

Set up your school

Menu, then Settings, then School details. Add the name, logo, terms and the current academic year.

2

Add classes and streams

Menu, then Classes. Add each class (P.1 to P.7, S.1 to S.6). Add streams only if a class has more than one group.

3

Invite teachers

Menu, then Teachers, then Invite. Each teacher gets an email link that works for 72 hours.

4

Add students and parents

Import a spreadsheet or add students one by one. Add each parent's phone number and tick "on WhatsApp".

5

Set fees

Menu, then Fees. Enter the amount per class for each term.

6

Publish results

Once the marks are in, publish them. Parents get the report card on WhatsApp.

Ask Toshi

Open the Toshi panel on any page and ask in plain words, for example "How many students are in P.5?"

Remember

Publishing sends messages to parents. Check the class before you publish.
