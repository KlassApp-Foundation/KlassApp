# Formal document template: handoff, 2026-10-01

- `HANDOFF.md`: the full spec for page, type, colours, first page, running header and footer, tables, the draft state, the five document types, signature blocks, a `.dotx` build checklist, and acceptance checks.
- `template/FormalDocument.dc.html`: the HTML/PDF template, a 3-page DPA sample. Open it in a browser; its paper (A4 or Letter) and draft state can be switched in the editor. `_ds_bundle.js` isn't included, and the template doesn't need it.
- `concepts/dpa-accept.html`: the in-app click-to-accept page for the data processing agreement, with five states: read and accept, errors, accepted, not the main admin, and new version. Shown at 1280 and 375.
- **Signed PDF:** turn on `signed` in the template to see the acceptance block that replaces the signature lines (HANDOFF section 12).
- `template/assets/`: the stacked light logo (first page) and the icon mark (running header). **For Word, export the logo as a 600 dpi PNG.**
- `design-system/`: the token stylesheets.

**Brand rule:** KlassApp is global, for schools from nursery to secondary, with no country-only framing. The founding-schools offer has no stated limit.

Contrast ratios are calculated from hex. Page fit was designed for both A4 and Letter; check it in your PDF export.
