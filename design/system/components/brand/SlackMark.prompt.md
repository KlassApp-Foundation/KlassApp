The official Slack mark (2019 hash) — used where a school's staff workspace is connected to KlassApp.

```jsx
<SlackMark style={{ width: 20, height: 20 }} />
```

Same rules as `WhatsAppMark`: no intrinsic size, never recolour the four-colour hash, `decorative` defaults to true. Pair it with `WhatsAppMark` and `GoogleDriveMark` in the "connected tools" row — 20px marks, 10px gap, label in `--d-text-secondary`.
