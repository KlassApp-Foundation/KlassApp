The official Google Drive mark — used where school documents (report cards, registers, uploads) live in a school's Drive.

```jsx
<GoogleDriveMark style={{ width: 20, height: 20 }} />
```

Same rules as `WhatsAppMark`: no intrinsic size, never recolour the triangle, `decorative` defaults to true. The viewBox is 87.3×78 (wider than tall) — set width and let height follow, or the mark distorts.
