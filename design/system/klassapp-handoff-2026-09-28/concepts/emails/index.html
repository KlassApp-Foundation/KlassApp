Email shell

One shell for every KlassApp email: a 600px table layout, system fonts, a PNG logo with alt text, 48px buttons in #15803D, and hex-only colours. Each email is shown at 600px and 375px, with its plain-text version below. The four mailcontent emails use production rows exactly as they appear in the database. Each one is flagged where a copy correction applies.

Dark mode applies the shell's own prefers-color-scheme rules. Clients that force-invert everything (the Gmail app) can't be previewed here.
