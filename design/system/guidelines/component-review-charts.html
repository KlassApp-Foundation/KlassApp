Charts

Built on the real <x-chart> wrapper: Chart.js 4.5.1 with its defaults (no legend, #0F172A tooltip with Sora titles and DM Sans body, 11px DM Sans ticks, no x grid, #F1F5F9 y grid, y axis from zero), the dsCenterValue doughnut plugin, and the built-in .ds-chart-empty swap. The three types the dashboards use are shown below — line (fee trend), doughnut (the gender split covered by DashboardGenderChartTest) and bar (admin/dashboard, the end-of-term KPI card). Each has a state switch.

Series palette — accessible from the start

Chart marks are graphics, so WCAG asks for 3:1 against the card, not 4.5. Every series colour clears 4.5 anyway, so the same colours work for legend text and direct labels. Bright #22C55E is excluded for the same reason as the frozen Pulse KPI: 2.28:1.

Order matters: blue then amber is the pair most people with red–green colour-blindness can still tell apart, so two-series charts never lean on green against red. Red is kept for "this is bad" (arrears, absence) and never used as an ordinary series colour. Doughnut segments get a 2px white border so neighbouring slices separate without relying on hue alone.
