Every size is generated from klassapp-icon.svg — the single source of truth. Safari needs apple-touch-icon as an opaque PNG at 180×180 (it ignores SVG and renders transparency as black), so that one gets a white plate. manifest.json must carry the real app name plus correct relative paths for both 192 and 512.
Regression guard. Legacy GeGoK12 orange icons shipped in production long after rebrand, alongside a broken manifest and missing sizes. Any new page or subdomain must serve the full set above from klassapp-icon.svg — see guidelines/favicons.md for the exact head tags and manifest fields.
