What changed, and why

ItemReal / newNotes
header textreal → .v2Sora 0.72rem uppercase in --d-muted 2.57:1 → --d-text-secondary 4.76:1. The 2px blue header rule, sticky thead and green hover rail are untouched.
sortreal + a11yUpstream shows sort with th.active + a rotated arrow, but screen readers get nothing. .v2 drives it from aria-sort, and headers are focusable (Enter/Space sorts). Numeric columns right-align their header to match .dt-cell-num.
searchnewThe v2 input with a 16px search icon (Icon.jsx path) and a 44×44 clear button. Matches name or admission number, debounced 150ms.
filtersnewPlain .ds-form-select.v2 dropdowns, not a custom filter popover. Each active filter becomes a removable chip: a 30px pill inside a 44px hit area, in the blue "informs" tint also used by .dt-badge-present.
selectionreal + newReal .dt-checkbox and tr.dt-selected (blue rail). New: the header checkbox goes indeterminate, and the toolbar is swapped for a dark bulk-action bar that counts the selection. Selection survives sorting and filtering.
paginationreal.dt-page-btn declares 36×36 but also min-width/height: 44px, so it renders 44 — measured …. The page resets to 1 on any search or filter change.
loadingnewFirst load: skeleton rows with the page's own column widths. Refresh: the rows stay and a 2px blue bar runs along the top, so nothing jumps. Both go static under reduced motion.
