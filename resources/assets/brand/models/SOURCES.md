# LLM brand marks (landing Toshi tower)

Source of truth: official press-kit / brand SVGs collected into `llm-brand-marks.zip`
(Anthropic, OpenAI, xAI Grok, Google Gemini, Moonshot Kimi, Z.ai).

DeepSeek is intentionally omitted from the shipped set.

Files:
- `<provider>.svg` — canonical mark
- `<provider>-mark.svg` — same bytes (tower references `-mark` for clarity)

Served at runtime from `public/images/brand/models/` (mirrors this directory).
Do not recolor or redraw path data.
