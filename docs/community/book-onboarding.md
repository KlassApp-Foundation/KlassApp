# Book onboarding

Want help getting your school live on KlassApp?

Email **[community@klassapp.xyz](mailto:community@klassapp.xyz)** with:

- School name  
- Rough student count  
- Whether you prefer **self-serve wizard**, **Toshi-assisted**, or a **live walkthrough**  
- Best contact WhatsApp or email  

We’ll reply with next steps. There is no separate booking API on this static docs site.
