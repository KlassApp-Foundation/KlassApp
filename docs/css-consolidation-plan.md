## Constraint

**DaisyUI requires Tailwind v3.** The project is on Tailwind v1 (`purge: false` config, `laravel-mix-tailwind` plugin). Upgrading Tailwind v1 → v3 is a separate scoped effort — not something to bundle with CSS refactoring.

**Recommendation:** Skip DaisyUI for this phase. Use Tailwind's existing utility classes plus dashboard-refresh.css custom properties as the theming layer.

## Execution Order

### Phase A — Admin Dashboard (address M2, M3, M4, L1, L2, L3)
1. Unify card padding to `p-5` (Tailwind spacing scale)
2. Pick one grid system: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4` (standardize on grid)
3. Replace 14+ hardcoded inline padding/margin with Tailwind classes
4. Fix chart canvas: `h-64` instead of fixed `250px`
5. Standardize empty states: `"No {item} yet."`
6. Consolidate 4 button patterns into CSS classes based on dashboard-refresh.css tokens

### Phase B — Toshi Widget (address M5, L6)
1. Extract inline styles into a `<style>` block within the Blade (quick win, no build step)
2. Then move to dashboard-refresh.css for shared rules
3. Move hardcoded position to CSS class

### Phase C — Landing Page (address M6, M7, L4, L5)
1. Wait for canonical version decision
2. Add aria-labels, alt text, prefers-reduced-motion
