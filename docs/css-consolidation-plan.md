## Execution Order

### Phase A — Admin Dashboard (address M2, M3, M4, L1, L2, L3)
1. Unify card padding to `p-5` (Tailwind spacing scale)
2. Pick one grid system: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4`
3. Replace hardcoded inline padding/margin with Tailwind classes
4. Fix chart canvas: `h-64` instead of fixed `250px`
5. Standardize empty states: `"No {item} yet."`
6. Consolidate button patterns into CSS classes based on dashboard-refresh.css tokens

### Phase B — Toshi Widget (address M5, L6)
1. Prefer package + published `toshi-ui.css` over Blade-only inline styles
2. Keep shared tokens in dashboard-refresh / package CSS
3. Use `position: fixed/absolute` for layout-critical Toshi chrome (Livewire reparenting)

### Phase C — Landing Page (address M6, M7, L4, L5)
1. Wait for canonical version decision
2. Add aria-labels, alt text, prefers-reduced-motion
