# Resend an invite link

Who: school admins.
Where: the person's profile. For a teacher: **Teachers and staff → open the teacher**.

When a teacher or class teacher is invited, they get a one-time link by email. The link lets them set their own password. If it expires or they lose it, resend it. The old link stops working the moment you resend.

## Steps

1. Open **Teachers and staff**.
2. Click the teacher's name to open their profile.
3. Click **Resend setup link** in the page header.
4. A dialog names the email address it will go to. Check it is the right person.
5. Click **Confirm resend**.
6. Tell the teacher to look for a new email and to set a password from that link.

The page confirms the send. If the teacher has never signed in, the profile shows the invite state; after they set a password, the resend button is no longer offered.

## What to know

- **The previous link stops working.** There is only one live link per person.
- **Staff setup links go by email only.** The dialog says WhatsApp is not sent for staff setup links.
- The link expires. The expiry is set by the school's invite settings; the email states it.
- If the email address is wrong, fix it on the profile first, then resend.
- Students and parents have the same **Resend setup link** action on their profiles. It works the same way and replaces the previous link.
- Class-teacher invites can be resent from the class's invite page (**Resend**) as well as from the teacher's profile.
