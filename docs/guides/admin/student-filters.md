# Filter students by class and stream

Who: school admins.
Where: **Students** (`/admin/students`).

The students page lists everyone active in the school. The chips above the list narrow it down. The address changes as you click, so you can bookmark a view.

## Steps

1. Open **Students**.
2. Click the **class** chip. A menu opens with the school's classes. Choose one.
3. The **Stream** row appears under the class chips. Click a stream to narrow to that stream.
4. Click the same chip again, or **Clear filters**, to go back to everyone.
5. Type in the search box to find a name inside the filtered list.

The class chip shows how many students are in that class. The stream chips show the streams that belong to the selected class. A class with no streams shows no stream row.

## What to know

- The filter is in the address bar: `standard` is the class, `stream` is the stream. Sharing the link shares the view.
- **Clear filters** clears the class, the stream and the search, and returns to the full list.
- The list is paged. The count on the chip is the class total, not the number on this page.
- Filtering changes what you see, not who is in the class. To move a student, open the student's profile.
