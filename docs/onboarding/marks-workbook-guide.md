# Filling the term's marks workbook

This workbook carries one term's marks from the school's own records into KlassApp. The official report cards are produced by KlassApp; the workbook is how the marks get in.

## Tabs

| Tab | What it is for |
| --- | --- |
| **Setup** | The school, academic year and term, and the three exam sets |
| **One tab per class** | The learners and their marks for that class |
| **Class Summary** | The totals, averages and positions for the class |

## Setup tab

Fill these once:

- **School** — the school name, spelled as it is in KlassApp.
- **Academic year** — for example `2026`.
- **Term** — for example `Term 2`.
- **Three exam sets** — for each one: its name (for example `Mid-term`), what it is **out of** (for example `100`), whether it is **on the report card**, and its **weight**.

Weights decide how much each set counts toward the term result. If the school does not weight exams, leave the weights equal.

## A class tab

Columns A to D are the learner:

| Column | What goes in it |
| --- | --- |
| A | Learner full name |
| B | Stream |
| C | Gender |
| D | KLS number (KlassApp fills it; leave blank if unknown) |

Then come three exam blocks, one per exam set on Setup. Each block has six subject columns. Type each learner's mark in the subject columns for that exam.

After the blocks: **Total**, **Average** and **Position**. These are calculated. Never type in them.

## How to enter a mark

- A number from `0` up to the exam set's **out of** value.
- `ABS` when the learner was absent.
- Leave the cell empty when the paper was not taken or the mark is not known yet.

Do not type `-`, `N/A`, a percentage sign or text in a mark cell.

## Class Summary tab

It repeats each learner's total, average and position for the class. It is a check for the school, not a second place to type marks.

## Names and streams

The learner's name and stream must match the onboarding checklist exactly. If the checklist says `Primary One` and `East`, the marks tab says `Primary One` and `East`, not `P.1` or `P1 East`. A name or stream that does not match is a row KlassApp cannot place.

## Positions

Positions rank learners by **total** marks in the class. A learner marked `ABS` scores nothing for that paper, so an absent learner ranks lower than a learner who sat the paper. Ties share a position; the next position skips the tied places.

## What happens next

1. The school fills the workbook and hands it in with the term's marks.
2. KlassApp imports the marks against the class and stream.
3. Teachers and the marks release step check the marks.
4. KlassApp produces the report cards from the released marks. The workbook is not a report card and is not sent to parents.
