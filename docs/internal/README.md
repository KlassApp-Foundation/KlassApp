# Internal working references

Working reference documents for KlassApp maintainers. **Not** published community
documentation (community docs live in the GitBook synced from `docs/community/`)
and **not** an onboarding path.

What belongs here:

- External/reference comparisons (other projects, licenses, patterns) kept as
  decision inputs.
- Working notes that support an explicit follow-up decision, where the value is
  the *evidence*, not a how-to.

What does **not** belong here: how-to guides, architecture explanations, or
anything a contributor is expected to read to get started — those live in
[`docs/`](../) (`architecture.md`, `docs/dev/`) or the GitBook.
