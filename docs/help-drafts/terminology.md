# Terminology

One definition per term, used the same way in every guide, screen and message. If a screen uses a different word for the same thing, that is a bug to report, not a second definition.

| Term | Definition |
|---|---|
| **Standard (Formal)** | The default report card template. On **Report Card Template** it is called **Formal**. It prints the headings MONTHLY RESULTS and END OF TERM EXAMINATION and is the card every existing school prints until it chooses another. |
| **New look (Progressive)** | The optional report card template, called **Progressive (new look)** on **Report Card Template**. One table; each exam set is a Marks and Grade group in exam-date order; it shows the total, aggregate, division and position for each set. It is not the default. |
| **Warm** | The second built-in report card template. It is neither the default (**Formal**) nor the **Progressive (new look)** card. |
| **Progressive report** | One of the two report types. It is the formal card described under **Standard (Formal)** — a monthly results table and an end-of-term table, a mark and a grade for each subject, and the aggregate, division and position where the class uses them. |
| **Set-based reports** | The other report type. Each exam set has its own report, and one combined report uses the weights for the sets that count toward it. Chosen on **Report cards → Report type**. |
| **Exam set** | One school's named set of exams for one term, for example a set the school calls "Opening paper". A school can have any number of sets, with its own names, in date order. Every set has its own report when it is released. |
| **Counting set** | An exam set that counts toward the combined report for the term, with a weight. The weights of the counting sets must total 100. A set that is not counting **stands alone** and has no weight. |
| **Missing** | No mark was entered for that learner and subject. It counts as 0 — grade F9, 9 points on the default scale — and is printed as **Missing**, never as 0. |
| **ABS** | The learner was absent. It counts as 0 in the same way as **Missing** and is printed as **ABS**. The stored grade is AB; every screen shows ABS. |
| **Incomplete** | A planned label for a set or card with missing marks. It is **not built**; do not use it as a current state. Today a missing mark prints **Missing** and counts as 0, and a counting set with marks entered but not released blocks the combined report. |
| **Aggregate** | The sum of the grade points for the subjects counted. Lower is better. On the default scale, four F9 grades give an aggregate of 36. |
| **Division** | The band the aggregate falls into: 12 or less = 1, 13–24 = 2, 25–28 = 3, 29–32 = 4, 33 or more = U. A school can save different ranges on **Progressive report rules**. |
| **Position** | The learner's place in the class, by aggregate (lowest first) or by total, depending on the ranking rule. A tie shares the place and the next place is skipped. Shown as "7th of 76". |
| **Released** | A report has been published for the class or school and families can see it. Before that, parents and learners see nothing. A released report keeps the rules and the mix it was released with; editing settings changes the next release, not the released one. |
