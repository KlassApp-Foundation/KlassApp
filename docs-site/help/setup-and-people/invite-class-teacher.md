# Invite a class teacher

A class teacher is the person who heads one class. The school assigns them from the class, either by picking a teacher already on staff or by inviting a new one by email.

## Open the invite page

- Open **Classes**, find the class, and press **Assign class teacher** (or **Replace class teacher** when one is set).
- Or, in the class list, press **Invite Class Teacher** on a class that has none.

The page is titled **Invite Class Teacher**.

## Invite someone new

1. Type their **Email**.
2. Leave **Existing teacher?** on the new-teacher choice.
3. Type **Teacher Name** and, if you have it, **Phone (optional)**.
4. Tick the confirmation: "I confirm this class teacher for CLASS. A mistake can be raised with the school admin who made the change."
5. Press **Send Invite**.

They get an email with a one-time setup link. The link lets them choose a password; it expires after 72 hours, works once, and stops working if a new link is sent.

## Assign a teacher already on staff

1. Open the same page.
2. Choose the teacher under **Existing teacher?**.
3. The **Email** box is still required. Type the address shown beside their name.
4. Tick the confirmation and press **Send Invite** (or **Replace class teacher**).

They are assigned straight away and get an email notice. No setup link is sent, because they already have an account.

## Pending invites

The bottom of the page lists **Pending invites** with **Email**, **Name**, **Status** and **Link**.

- **Pending** — the link has not been used and has not expired.
- **Expired** — the 72 hours have passed. Press **Resend**.
- **Resend** sends a fresh link and replaces the previous one.

A new invite for the same class, or replacing the class teacher, revokes the pending invite for that class.

## What the teacher does

1. Opens the link in the email.
2. Chooses a password.
3. Signs in and finds the class in **Classes**, with **Report Cards** when that screen is on for them.

## Notes

- The email is sent to the address you type. Check it before sending; a wrong address cannot be corrected, only replaced with a new invite.
- An address that belongs to someone at another school gets the same response as a new address. If they open the link, the page tells them the email cannot be used and to ask the school for a different one.
- A person who never receives the email should check spam, then the school should resend from this page.
