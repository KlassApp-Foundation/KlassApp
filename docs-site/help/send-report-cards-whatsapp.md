# Get the report card on WhatsApp
Parents do not need to install anything: the report card arrives in the parent's WhatsApp chat with the school's KlassApp number.

## For admins: what sends, and when

<Steps>
<Step title="Approve the marks">

Report cards only go out for a student whose marks for the term are approved. Approve the marks in <UiPath to="Exams & Marks" /> before you tell parents the cards are ready.
</Step>
<Step title="Parents ask with one word">

A parent sends the word "report" to the school's KlassApp number. KlassApp replies with the child's report card as a PDF.

</Shot>
</Step>
<Step title="More than one child">

If a parent has more than one child at the school, KlassApp asks which child. The parent replies with the number next to the child's name.
</Step>
</Steps>

::: tip
The download link in a parent's chat works for 7 days. After that the parent sends "report" again.
:::

## What parents see
The report card is a PDF — the same pages as Download Individual Reports on the Report Cards page.

::: warning
Marks that are not yet approved show as "Marks are not yet finalized for this term" to a parent who asks. Approve the marks, or tell parents when to expect the cards.
:::
