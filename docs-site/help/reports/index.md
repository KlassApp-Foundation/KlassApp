# Reports and marks

How a school turns marks into report cards: the report type, the rules behind the numbers, the marks themselves, the release, and the card.

These guides describe draft work. Each page names the pull request it waits on in its front matter. Until that pull request merges, the screen may not be on your school yet.

## Set up the report

- [Choose a report type](/help/reports/choose-report-type) — Progressive report or Set-based reports.
- [Progressive report rules](/help/reports/progressive-report-rules) — grade points, division ranges, ranking, presets and reset.
- [Exam types and exam sets](/help/reports/exam-types-and-sets) — your own set names, which sets count, weights, column order.
- [Crest, head teacher name and uploads](/help/reports/crest-head-teacher-uploads) — the card's identity, and what a deploy can remove.
- [Make a term current and link a class](/help/reports/setup-actions) — the two setup actions, with their confirmations.

## Marks and release

- [Missing marks and ABS](/help/reports/missing-marks-and-abs) — both count as 0, shown as Missing or ABS.
- [Enter marks on a phone](/help/reports/enter-marks-phone) — cards, ABS, Save draft, offline, Submit.
- [Approvals and release](/help/reports/approvals-and-release) — who submits, approves, returns and releases; release without notifying; re-release.

## Start to finish

- [Your first term of reports](/help/reports/first-term-checklist) — the order to do everything in.

## In preparation

Placeholder pages exist, with headings only. They will be written when a pull request or the code names the screen:

- [Report builder](/help/reports/report-builder) — a report for any set or any combination of sets.
- [Comment bank](/help/reports/comment-bank) — comments a school can edit and disable, with a minimum number of options.
- [School calendar](/help/reports/school-calendar) — the official calendar, the current term, and a school override with a reason.

Do not walk a school through any of these until the screen exists.
