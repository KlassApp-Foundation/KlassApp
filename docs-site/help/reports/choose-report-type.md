# Choose a report type

A school prints one kind of report. You choose it once and change it only when you mean to. Existing schools keep the **Progressive report**, so nothing changes until you choose otherwise.

## Choose the type

1. Open **Report cards** (`/admin/reports/cards`).
2. Find the section **Report type**.
3. Choose one:
   - **Progressive report** — the formal card titled PROGRESSIVE REPORT. It has a monthly results table and an end-of-term table, a mark and a grade for each subject, and the aggregate, division and position for classes that use them.
   - **Set-based reports** — each exam set has its own report, and one combined report uses the weights for the sets that count.
4. Press **Save report type**.

The page says a change applies from the next release. A report that has already been released keeps the type it was released with.

## If you choose Set-based reports

Two columns appear on **Exam Type Settings**, not on this page:

- **Show on Report Cards**
- **Weight %**

The weights of the sets that count toward the same combined report must total 100. See [Exam types and exam sets](/help/reports/exam-types-and-sets).

## Who can change it

A school admin and a head teacher. A teacher cannot open the setting.

## What does not change

The card's headings, its grade bands, and how a blank mark is scored stay as they are until you change them on [Progressive report rules](/help/reports/progressive-report-rules) or release a term with different rules.
