# Approvals and release

Marks move in one order: **save → submit → approve → release**. Each step has its own screen, and the school can see who did what.

## Who can do what

| Step | Who |
| --- | --- |
| Enter, save, submit | A subject teacher for their own subjects; a class teacher for their class; a school admin or head teacher for any class in their own school |
| Approve or return | A class teacher for the class they head; a school admin or head teacher for any class in their own school |
| Release | A school admin or a class teacher for their class. A head teacher is refused on **Marks Release** in this draft |
| Reopen | A site admin, school admin or head teacher of that school, with a reason |

A teacher cannot open the school-wide approvals queue. A class teacher sees **Review marks** and only the classes they head. A subject teacher who does not head the class does not see it.

## Read the class mark sheet first

1. Open **Exams and marks**.
2. Pick the class and the term.
3. Each exam set that has a sitting is a tab, in date order, under your school's own name.

On a phone the tab row scrolls inside itself; the page does not scroll sideways. Before a set is released, a subject that is not in the total shows a dash. After release, a blank mark says **Missing**. **ABS** stays ABS. A reopened subject still shows its mark. Teachers do not get this combined sheet; parents never see it.

## Approve or return

1. Open **Review marks** (class teacher) or the approvals queue (admin or head teacher).
2. Read the subject, class, sitting and teacher.
3. Press **Approve**, or return the subject with a reason of at least 10 characters.
4. The teacher sees the return note on their exam list and on the enter-marks notice.

The release page refuses until every subject in the set is approved.

## Release

1. Open **Marks Release**.
2. Choose the set and the class.
3. Read the preview: it names the set, shows **ABS** for absences, and states how many marks are missing, for example "12 marks are missing and will count as 0".
4. Choose who is told under **Who receives this release**:
   - **Everyone in this class** — every approved, linked, opted-in parent of the class.
   - **Only the people I choose** — a named list. The rest of the class is not told.
5. Press **Preview who will be told** and read the names and the sentence each person receives.
6. Press **Confirm and release** (or **Confirm schedule**).

The confirm button names the outcome, for example "Release Mid Term marks to 2 classes".

## Release without notifying

Leave **Send these results on WhatsApp** off when the release should not message anyone. The release still happens; the log says the messages are switched off. This is the safe choice for a first release.

## Only some people

**Only the people I choose** stores the list on the release. An empty list messages nobody and does not fall back to the class. If a chosen parent is not linked, has no number, or the learner is not in the class, the preview refuses with the reason and the release log records the skip.

A pilot tells one parent, one child, one message. Opt-outs are honoured.

## Re-release and reopen

- A second release of the same sitting asks for a reason of at least 10 characters.
- **Reopen marks** asks for a reason too. The status line reads: "Reopened. Families keep seeing the released results until you release again."
- A released report does not change when the rules or the mix change. A new release writes a new version; the old one keeps its numbers.

## What families see

Nothing before release. After release, the parent sees the released report; a later reopen does not withdraw it until the school releases again.
