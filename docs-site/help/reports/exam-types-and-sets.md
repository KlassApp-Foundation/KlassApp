# Exam types and exam sets

An exam set belongs to your school and to one term. You can have any number of sets, with your own names, in date order. **Beginning of Term**, **Mid Term** and **End of Term** are starter names only. Nothing on the report depends on those words.

## Name your sets

1. Open **Settings**, then **Exam types**.
2. Each starter name is an editable box. Type the name your school uses.
3. For each set, choose one:
   - **Counts toward the combined report**
   - **Shown on its own**
4. If any set counts, the **Weight %** values of the counting sets must total 100 before **Save report settings** works.
5. Press **Save report settings**.

The page shows **Made up of** and **Adds up**, so you can see the mix before saving. It also says: "Applies from the next release. Reports already released keep the mix they were released with."

Saving a new name does not change the shared catalog for other schools. It changes your school's copy.

## Create the sets

1. Open **Exams and reports**, then **Exam sets**.
2. Choose the term, the sets, and the classes.
3. Submit the form on that page.

Each set still has its own report when it is released, whether it counts toward the combined report or stands on its own.

## Column order follows the exam date

Columns and combined sheets follow the field **Scheduled Date & Time** on the exam form. The earliest date comes first. A set with no date goes last. If two sets share a date, the term that starts earlier comes first, then the term's id. The order the sets were created is not the order.

Set the date on the admin exam form or the teacher exam form.

## Who can change this

A school admin and a head teacher, for their own school. A teacher cannot open **Exam types**.

## What a released report keeps

A released report keeps the mix it was released with. Changing **Exam types** changes the next release, not a report that is already out.
