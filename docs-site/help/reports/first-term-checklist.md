# Your first term of reports

A short checklist for the first term in which a school prints report cards. Do the steps in order; each one leaves the next step possible.

## 1. Set the term

Open **Academic Terms** and press **Make this the current term** on the term you are working in. Confirm it. See [Make a term current and link a class](/help/reports/setup-actions).

**Check:** the term is marked **Current term**, and the academic year is active.

## 2. Link the classes

Open **Classes**. If a yellow box lists sections with no link, press **Link to a class**, choose the class, and confirm.

**Check:** every section you will report on has a class link for the current year.

## 3. Load the learners

Open **Students**, then **Import a list**, or add learners one at a time. Each learner gets a KLS number from the school's sequence.

**Check:** the class list has the right count, every learner has a KLS number, and none is in the wrong class.

## 4. Name the sets and create them

1. Open **Settings**, then **Exam types**. Give each set your school's name. Choose **Counts toward the combined report** or **Shown on its own**. If any set counts, the weights must total 100. Press **Save report settings**.
2. Open **Exams**, then **Exam sets**. Choose the term, the sets and the classes, and submit the form.
3. On each exam, set **Scheduled Date & Time**. The report's columns follow that date.

**Check:** each set has the right subjects and the right class; the column order is the order you expect.

## 5. Enter or import the marks

- Teachers: **Marks**, then **Enter marks**. Press **ABS** for an absence. **Save draft** as you go; **Submit** when every learner has a mark or ABS.
- Office: use the per-exam page **Paste or upload marks** for a spreadsheet. Preview first; read every skipped row.

**Check:** the missing count is zero, or every remaining gap is an absence you know about.

## 6. Approve

Class teachers approve on **Review marks**. School admins and head teachers approve from the approvals queue. A return needs a reason of at least 10 characters.

**Check:** every subject in the set is approved.

## 7. Check the card before you release

1. Open **Report cards** and choose the class.
2. Press **PDF** for one learner, or **Open sample** on the template screen for a sample marked SAMPLE FOR APPROVAL.
3. Read one strong learner, one middle learner and one with a gap.

**Check:** names, KLS numbers, class, term, marks, Missing and ABS are right; the card is one page.

## 8. Release

Open **Marks Release**. Read the preview and the missing count. Leave **Send these results on WhatsApp** off for the first release. Press **Confirm and release**.

**Check:** the release is listed with its time and who released it; the log shows each family as sent, skipped or switched off.

## 9. Print or share

- From **Report cards**, download the class PDF or one card per learner.
- Families see the report only after release; a parent can ask for the card on WhatsApp when one is available.

**Check:** two families confirm they see their own child's report and nothing else.

## If something is wrong after release

Fix the mark, then release again with a reason. A released report does not change by itself; a new release writes a new version and the old one stays in the history.
