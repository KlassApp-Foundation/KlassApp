# KlassApp for teachers
Teachers share one login. What else you see depends on the class you are given.

<RoleCards :items="[
 {title:'Class teacher',text:'Homeroom for a stream: exams and report cards as well as marks',link:'/docs-preview/help/teachers/class'},
 {title:'Subject teacher',text:'Your subjects: classes, homework, and marks',link:'/docs-preview/help/teachers/subject'}]" />

Sign in at the KlassApp login page. You open the teacher dashboard.

A head teacher is not this login. That account uses the school menu. See [Head teacher](/help/head-teachers/).
