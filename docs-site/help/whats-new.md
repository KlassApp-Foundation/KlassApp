# What's new

## November 2026 — reports and marks guides (in draft)

A new set of guides covers the report-card work now in review:

- **Choose a report type** — Progressive report or Set-based reports, saved on **Report cards**.
- **Progressive report rules** — grade points, division ranges, ranking, presets and reset.
- **Exam types and exam sets** — your own set names, which sets count, weights, and column order by exam date.
- **Crest, head teacher name and uploads** — where the crest is stored, and what a deploy can remove.
- **Make a term current and link a class** — the two setup actions and their confirmations.
- **Missing marks and ABS** — both count as 0 and print as Missing or ABS. There is no Incomplete state.
- **Enter marks on a phone** — cards, the ABS button, **Save draft**, offline retry, and when **Submit** turns on.
- **Approvals and release** — who can submit, approve, return and release, releasing without notifying, and re-release with a reason.
- **Your first term of reports** — the whole path in order.

- **Answers for support** — short questions and answers to use in chat or on WhatsApp, each linked to a guide.

These pages are drafts until the pull requests named in each page's front matter merge. Nothing on this page describes a screen that is live today.

Placeholder pages are in place for the report builder, the comment bank and the school calendar. They carry headings only and will be written when a pull request or the code names the screen.

The guides live under [Reports and marks](/help/reports/).
