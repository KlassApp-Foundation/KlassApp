# Enter marks
Put exam marks in per class and subject. Teachers can enter marks for their own subjects; admins can enter any of them, from here.

## Steps
<Steps>
<Step title="Open Exams & Marks">

In the sidebar, choose <UiPath to="Exams & Marks" />.

<Shot src="/docs-preview/img/admin-exams_2026-10-01.webp" alt="Exams & Marks page" url="app.klassapp.xyz/admin/exams" :w="1280" :h="720" caption="Desktop 1280 × 720 · demo school">
</Shot>
</Step>
<Step title="Open the exam">

Choose the exam for this term. Create it first if this is a new exam.
</Step>
<Step title="Choose class and subject, then enter marks">

Pick the class and subject, then type each student's marks. Marks are grouped by the term you set in Settings.
</Step>
</Steps>

::: tip
Watch the Missing Marks Report to find subjects nobody filled in yet.
:::

## What happens next
Generate report cards once all the marks are in.
