# Book a setup session

::: info Coming soon
There is no booking page in KlassApp, and no calendar to pick a time.
:::

Email [community@klassapp.xyz](mailto:community@klassapp.xyz) and say you want help with setup. Include your school name and the email on the account.

You can still set the school up yourself. See [Get started](/help/getting-started) and [Onboarding paths](/help/admins/onboarding).
