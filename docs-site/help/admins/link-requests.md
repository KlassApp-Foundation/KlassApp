# Review link requests
Parents ask to link a WhatsApp number to a child. You approve or reject that request.

## Before you start
You need the school admin menu. Open <UiPath to="WhatsApp" />. The page title is **WhatsApp**. The subtitle is "Link requests from parents, numbers linked now, and message delivery."

The same waiting count can show on the **WhatsApp** menu row.

## The Link requests list
The first section is **Link requests**. The line under it is "Parents asking to link a child, by KlassApp number, form, or demo. This list updates by itself."

Each card shows the parent name or phone, a source chip (**KlassApp number**, **Form**, or **Demo**), and the child name with class and stream when the school has them.

If the names do not match one student, the card says **Parent typed** and what they entered.

<Steps>
<Step title="Approve a clear match">

When the card already has one student, choose <Btn>Approve</Btn>.

When several students match, use the **Choose student** list, then <Btn>Approve</Btn>.
</Step>
<Step title="Send an unclear request to Approvals">

If the card has no student to pick, choose <Btn>Choose student</Btn>. That opens <UiPath to="Approvals" />.
</Step>
<Step title="Reject">

Choose <Btn>Reject</Btn>. Confirm with <Btn>Yes, reject</Btn>, or <Btn>Cancel</Btn> to keep the request.
</Step>
</Steps>

An empty list says **No link requests waiting.**

## Linked now
Under the requests, **Linked now** lists numbers already tied to a student. Choose <Btn>Unlink</Btn>, then <Btn>Yes, unlink</Btn>, to remove one. **Cancel** leaves it linked.

A demo link shows the time left. A school link stays until you unlink it.

The full parent list is **See linked parents**, which opens the WhatsApp linked-parents page. There the action is also <Btn>Unlink</Btn>.

## What happens next
Approving sends the parent a WhatsApp message and links the number. They can then ask for fees, results, attendance, and the report card. See [WhatsApp for parents](/help/parents/whatsapp).

The same parent-link rows also appear in [Approvals](/help/admins/approvals), labelled **Parent link (WhatsApp)**.
