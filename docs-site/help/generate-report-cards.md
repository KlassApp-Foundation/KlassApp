# Generate report cards

This guide is a short placeholder. The step-by-step report-card flow will be written when that work is on `main`.

School admins and head teachers open report cards at <UiPath to="Exams and reports > Report cards" />. A class teacher who is the homeroom teacher also has **Report Cards** in the teacher menu.

Parents can ask for a card on WhatsApp when one exists. See [Use KlassApp on WhatsApp](/help/parents/whatsapp).
