# Generate report cards
Turn the approved marks into PDF report cards, one per student or one merged PDF per class.

## Before you start
All marks for the term must be entered. Check the Missing Marks Report — you find it on the Report Cards page.

## Steps
<Steps>
<Step title="Open Report Cards">

In the sidebar, choose <UiPath to="Report Cards" />.

<Shot src="/docs-preview/img/admin-report-cards_2026-10-01.webp" alt="Report Cards page" url="app.klassapp.xyz/admin/reports/cards" :w="1280" :h="720" caption="Desktop 1280 × 720 · demo school">
</Shot>
</Step>
<Step title="Choose the class and term">

Use the filter to choose the class and the term.
</Step>
<Step title="Download">

Choose <Btn>Download Individual Reports</Btn> for one PDF per student, or <Btn>Merged PDF</Btn> for a single file with the whole class. <Btn>Download All</Btn> and <Btn>Print All</Btn> are there for the full set.

</Step>
<Step title="Pick a template">

Under Report Card Template, choose Formal or Warm. The template applies to all report cards generated from that point on.
</Step>
</Steps>

::: tip
Recent Generations at the bottom of the page lists what you downloaded before, so you can re-download without regenerating.
:::

## What happens next
Parents ask for the report card on WhatsApp.
