# Set up your school
Finish setup in the Wizard or with Toshi. The steps, button names, and how to switch paths are on [Onboarding paths](/help/admins/onboarding).

## Where to start
- Invite: the page **How would you like to set up** your school. Choose <Btn>Set up step by step</Btn> or <Btn>Set up by chatting with Toshi</Btn>.
- Open sign-up: the dashboard banner **Finish school setup**, then **Set up manually**.

## Edit details later
School admins open <UiPath to="Settings" />.

- **School details**
- **Academic years and terms**
- **Data exports**

Head teachers do not see **Settings**.
