# Set up your school
Name the school, add the logo, and set the academic year and terms.

## Before you start
You must be signed in as the admin who signed the school up.

## Steps
<Steps>
<Step title="Open Settings">

In the sidebar, choose <UiPath to="Settings" />.

<Shot src="/docs-preview/img/admin-settings_2026-10-01.webp" alt="KlassApp admin settings page" url="app.klassapp.xyz/admin/settings" :w="1280" :h="720" caption="Desktop 1280 × 720 · demo school">
</Shot>
</Step>
<Step title="Check the school details">

Confirm the school name. This name appears on report cards and every message parents get.

<Mark box :x="55" :y="20" :w="40" :h="12" />
</Step>
<Step title="Set the academic year and terms">

Set the current academic year and the term dates. Everything else — attendance, marks, fees — is grouped by term.
</Step>
</Steps>

::: tip
Term dates can be changed later, but the *current* academic year must be right before you enter marks.
:::

## What happens next
Add students, and tick "on WhatsApp" for each parent.
