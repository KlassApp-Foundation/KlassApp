# Use KlassApp on WhatsApp
Message the school's KlassApp number. You do not install an app.

## Link your number
Until your number is linked to a child, the welcome buttons are **Try Demo**, **Link help**, and **Request Link**.

<Steps>
<Step title="Ask to link">

Send the child's student ID if the school gave you one. A single match links at once.

Or send the child's KlassApp number (it starts with KLS). That files a request. The school has to approve it.

Or tap **Request Link** and complete the form.
</Step>
<Step title="Wait for approval">

The school reviews the request on **Link requests** or **Approvals**. You get a WhatsApp message when it is approved or rejected.
</Step>
</Steps>

## What you can ask
Send `menu`, or say hello. Choose <Btn>Open menu</Btn>. The parent list is:

- **Fee Balance**
- **Exam Results**
- **Attendance**
- **Report Card**
- **Help**
- **Demo**
- **Dashboard**

You can also type `fees`, `marks`, `grades`, `attendance`, or `report`.

**Report Card** replies with the report card PDF when the school has one for this term. If the marks are not ready, the reply is: "Marks are not yet finalized for this term."

**Dashboard** sends a link to the parent website. The website menu is **Dashboard**, **Children**, **Fees**, **Grades**, and **Attendance**. With one child, Fees, Grades, and Attendance open that child. With more than one, they open **Children** so you can pick.

## On the school website
Sign in with the email and password the school gave you, or with the **Dashboard** link from WhatsApp.

See [KlassApp for parents](/help/parents/) for the website menu.

::: warning
Do not send another family's student ID. The school approves KlassApp-number requests and can reject a request that does not match.
:::
