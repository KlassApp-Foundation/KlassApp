# Marks to a parent, end to end

**Draft.** This walkthrough is written for the stable release. The screens are from a demo school and are not yet a promise of the released product.

This is the shortest path from a teacher's mark to a parent holding the report card.

```
Enter marks  →  Approve  →  Release  →  Report card  →  WhatsApp to the parent
   teacher      class teacher   school admin    school admin     parent
```

## Who does what

| Step | Who | What they do |
|---|---|---|
| Enter marks | Subject teacher, class teacher, school admin or head teacher | Type a mark or **ABS** for each learner, then **Submit**. |
| Approve | Class teacher for their class; school admin or head teacher for any class | Approve, or return with a reason. |
| Release | School admin or class teacher | Check the preview, then release. Notifications can stay off. |
| Report card | School admin, head teacher, class teacher | Open **Report cards**, choose the class, print or download. |
| WhatsApp | Parent | Asks the school's KlassApp number for **REPORT**, or opens the app. |

## The rules that decide what a parent sees

- **Missing counts as zero.** A subject with no mark prints **Missing**, takes grade F9 and 9 points, and still counts in the total and the aggregate. The card is still produced.
- **An unapproved subject shows a dash.** Until the subject is approved and released, it is not part of the learner's total on the report. It is not guessed and it is not filled with a zero on screen.
- **Only released and included sets count.** A set that is not released, or is set to stand alone, does not join the combined report total.
- **Marks print as whole numbers.** A mark is rounded once, half up, when it is printed. 72.5 prints as 73; 72.4 prints as 72.
- **Division comes from the four core subjects.** The division is calculated from the aggregate of the four core subjects, using the school's division ranges.
- **A parent is linked in one of two ways:** the parent sends the child's KlassApp number to the school, or the school links the parent through the link-request form. One parent, one child, one record.
