# Exam sets, and managing exam types

Who: school admins.
Where: **Exams and reports → Exam sets** (`/admin/exams/sets`).

An **exam set** is one term's exams, created for every class and subject at once. Teachers then enter marks under **Marks**.

## Create a set

1. Open **Exams and reports → Exam sets**.
2. Click **New set**.
3. Choose the **Term**. If no terms exist, the page says so and links to academic terms.
4. Tick the **exam types** this set should create, for example Mid-term and End of term. The exam types come from the school's settings.
5. Leave **Whole school** ticked to create the set for every class, or untick it and pick classes and streams.
6. Under **Classes**, open a class to tick streams. A class with no ticks uses all its streams.
7. Click **Create exam set**.

The set is created immediately. The set page then shows a grid of classes and subjects with the exams that exist, and a delete action on each exam. Deleting an exam removes that one exam; it does not delete the set.

## Manage exam types

1. Open **Settings**.
2. Choose **Exam types** (`/admin/settings/exam-types`). The same link sits on the create-set page as **Manage exam types**.
3. Add a type, rename one, or change whether it counts toward results.
4. Save.

Exam types are school-wide. A type that is turned off does not appear when you create a new set; existing exams keep their type.

## What to know

- One set creates many exams. It does not enter marks and it does not release results.
- A set belongs to one term. To cover a second term, create a second set.
- **Manage exam types** is the only place exam types are edited; the set page links to it but does not edit them.
- If a class or subject is missing from the grid, check that the class has streams and the subject is attached to the class.
