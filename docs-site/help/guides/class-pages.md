# Class pages with stream cards

Who: school admins and class teachers.
Where: **Classes and subjects → Classes** (`/admin/classes`), then open a class.

A class page shows the class as a set of **stream cards**. Each card is one stream, how many students are in it, and its level. Below the cards is the roster for the stream you pick.

## Steps

1. Open **Classes and subjects → Classes**.
2. Find the class and click it. Classes are listed by level: nursery, primary, then secondary.
3. The page shows one card per stream. Each card has the stream name, the number of students, and the level.
4. Click a card to show that stream's students underneath.
5. Click **Edit stream** on a card to change its name or details.
6. Click **Assign class teacher** or the class-teacher link to invite or change the class teacher.
7. Use **← All classes** to go back.

If a class has no streams, the page says **No streams configured** and shows the class roster without cards. If a stream has no students, its card is still there and the roster says so.

## What to know

- A card is a stream, not a whole class. A class with three streams has three cards.
- The number on the card is the stream's student count. It is not the class total.
- A class teacher sees the same page for the class they head, including every stream.
- Editing a stream changes its name and details; it does not move students.
