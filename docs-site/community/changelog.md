# Changelog

## 2026-11-16 — reports and marks guides (draft)

Added a **Reports and marks** section to Help. It covers:

- choosing a report type;
- progressive report rules (bands, divisions, ranking, presets, reset, history);
- exam types and exam sets (own names, counting weights, column order by exam date);
- the crest and head teacher name, and how deploys affect uploads;
- the two setup actions: make a term current, link a class;
- missing marks and ABS (both count as 0; no Incomplete state);
- entering marks on a phone;
- approvals and release, including releasing without notifying and a chosen list of people;
- a first-term checklist.

These pages are documentation drafts. They name the pull request each depends on in the page's front matter, and they describe no screen that is live yet.

Still to write, when the screens exist: report builder, comment bank, and school calendar.

Docs index updated: `/help/reports/`.
