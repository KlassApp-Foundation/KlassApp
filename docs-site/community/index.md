# Community

These pages are for people who run KlassApp from the source, or who want to change it.

Schools looking for menus and setup should use [Help](/help/).

## Start here

- [Local setup](/community/getting-started) — PHP, Node, MySQL or Docker, then the app.
- [Tests](/community/tests) — PHPUnit, the full-suite guard, and Playwright.
- [Architecture](/community/architecture) — tenancy, role portals, WhatsApp, and Toshi.
- [Contributing](/community/contributing) — sync `main`, small pull requests, no secrets.

## Build on it

- [Packages](/community/packages) — the one package on `main`, and the open package proposal.
- [WhatsApp](/community/whatsapp) — the Meta Cloud API path and the local simulator.
- [Connectors](/community/connectors) — what a school can connect today. Google tools are Coming soon.

The source is public on GitHub; supported self-hosting opens after an independent security review.
