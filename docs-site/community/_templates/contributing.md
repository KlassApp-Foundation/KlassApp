# Contributing
## Before you start
Sync from the latest `main`.

## Pull request rules
- One change per PR, small and atomic.
- Real verification evidence (test output, screenshots) in the PR description.
- Multi-tenant end to end: `school_id` on every query.

## Tests
## The public-repo rule
::: danger This repository is public
Never commit secrets, `.env` values, real student, parent or school data, phone numbers, or screenshots of a real school. Use Demo Academy Uganda. If you commit something by mistake, tell the maintainers at once — rewriting history is not enough.
:::
## Review
External PRs get a human review before merge.
