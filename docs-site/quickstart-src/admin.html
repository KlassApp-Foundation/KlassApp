KlassApp quick start

Get your school running in KlassApp.

For admins
1

Sign up and confirm email

Open app.klassapp.xyz and tap Sign up. Enter the verification code we email you.

2

Set up your school

Menu, then Settings. Name the school, set the current academic year, and add the school logo.

3

Add students and parents

Menu, then Students. Tap Add student for one, or Import list to import a spreadsheet. Add each parent's phone number and tick "on WhatsApp".

4

Enter marks

Menu, then Exams & Marks. Open the exam, choose a class and subject, and enter the marks. Teachers can enter their own.

5

Generate report cards

Menu, then Report Cards. Choose the class and term, pick Download Individual Reports or Merged PDF.

6

Send them on WhatsApp

Once marks are approved for the term, a parent sends report to the school's KlassApp number and gets the report card as a PDF.

Help in the app

The full guide is one tap away: Menu, then Help & Docs. Full guide: docs.klassapp.com

Remember

Check the class before you enter or approve marks. Approved marks are what parents see.
